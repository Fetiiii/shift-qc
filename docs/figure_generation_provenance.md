# Figure provenance

The portable generator is derived from frozen task041_figures.py numeric
plotting definitions and the task042_figures.py neutral conceptual Figure 1.
Their input hashes and transformation are recorded in the release manifest.
Only file locations, availability checks, CLI/output routing and deterministic
vector metadata are adapted. PDF timestamps and SVG dates are omitted; SVG
element identifiers have a fixed hash salt. These changes do not alter the
image or scientific coordinates.
No scientific plotting coordinates or outcomes are manually changed.

Figure 1 has no scientific-result input. Figures 2 and 3 require the locally regenerated
mixed evaluation ledger; Figure 4 requires locally regenerated M&Ms supporting results.
The frozen numeric functions remain inspectable, but numeric regeneration
requires the independently regenerated original input contract. Figures2–4 drawing functions retain frozen AST identity; data-dependent entry points have controlled errors.
