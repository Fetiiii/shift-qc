## Private staging conventions

The layout examples above are relative placeholders, not configured environment variables or internal filesystem locations. For authorized local use, keep each collection in its own private staging location outside the project repository. Preserve custodian-provided folder names and filenames. Keep annotations separate from images when the custodian distributes them separately. Retain the source citation, terms, acquisition note, and provenance alongside each private copy.

For full local reproduction, see the [full reproduction guide](full_reproduction.md). It explains required source inputs and how to regenerate manuscript outputs from authorized local copies. No aggregate ledger is bundled here.

This repository redistributes none of the upstream source files. The current M&Ms agreement/version applying to this project remains unknown, and no blanket permission for mixed-source derived outputs is asserted here.
