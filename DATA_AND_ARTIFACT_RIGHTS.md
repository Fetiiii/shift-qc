# Data and artifact rights

This is a software/public-safe reproducibility package, not a medical-data deposit.
Original SHIFT-QC source code has separate copyright/licensing authority.
The author declared no BAP/funding/employment/IP assignment/proprietary-code constraints
and independently created the project. MIT covers original software source under
src/, scripts/, tests/ and configs/ only. It does not cover upstream data,
excluded derivatives, third-party code or their rights.

Upstream medical datasets retain their original rights. This repository grants
no rights over those datasets. Dataset citations and public access do not imply
redistribution authority. Patient-level and source-data-derived artifacts are
not redistributed in the initial release; no excluded artifact is relicensed.

Excluded: medical images/masks/archives, patient q_true/q_hat/features/split IDs,
predictions/probabilities, trained QC/segmentation weights, and unresolved derived
endpoint inputs, including aggregate ledger. Mixed-source validation cannot
inherit the most permissive component license. No compatibility license is invented.

Acquire inputs independently from official custodians and comply with each
applicable agreement, attribution and license. See docs/data_access.md and
 docs/full_reproduction.md. Locally regenerated artifacts are under the applicable
source conditions; placing them in a local ignored directory grants no new rights.

Conceptual Figure 1, documentation and synthetic fixtures contain no patient-derived
scientific result. They are distributed with the author’s authorized release permission, with all
rights reserved for documentation, citation metadata and conceptual output images.
No additional reuse license is silently assigned. Software/configuration files
use MIT as scoped above. A Zenodo software record must disclose this mixed scope;
its MIT software metadata does not relicense documentation, figures or data.
